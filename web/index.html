Cómo funciona

Tres pasos para empezar a registrar.

Crea un usuario

Da de alta a la persona que quieres monitorear.

Registra la medición

Envía el valor de glucosa en mg/dL a la API.

Consulta el historial

Obtén todas las mediciones del usuario cuando las necesites.

Un ejemplo rápido

Así se vería registrar una medición (ajusta la URL y los campos a tu API).

// Registrar una medición
POST /api/mediciones
{
  "usuarioId": 1,
  "glucosa": 98,
  "unidad": "mg/dL"
}

// Consultar el historial de un usuario
GET /api/usuarios/1/mediciones
